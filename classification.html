傷口分類總覽

一、急性傷口

1. 外傷性傷口（撕裂、切割、擦傷、穿刺、撕脫、壓砸）

評估重點：受傷機轉、時間、汙染程度、深度與組織缺損、神經血管肌腱檢查、異物、破傷風疫苗史。

處置原則：充分沖洗（生理食鹽水／飲用水等張沖洗）→ 必要之清創 → 依傷口條件選擇一期縫合、延遲縫合或二期癒合 → 感染預防（僅高風險考慮預防性抗生素）。

依據：Nicks 2010 (Int J Emerg Med, DOI:10.1007/s12245-010-0217-5)；Forsch 2017 (Am Fam Physician, PMID 28671402)；WHO Essential Trauma Care；SA Health Acute Minor Wound CPG
2. 皮膚撕裂 Skin Tears（ISTAP Type 1–3）
分型定義處置重點
Type 1皮瓣完整，可復位覆蓋全部傷口床輕柔復位皮瓣，矽膠接觸層固定
Type 2皮瓣部分缺損，無法完全覆蓋復位可存活部分，低創傷吸收敷料
Type 3皮瓣完全缺損低創傷敷料維持濕潤環境

關鍵：敷料拆除方向須順皮瓣（在敷料上畫箭頭）；脆弱皮膚避免強黏性薄膜、水膠體與免縫膠帶。

依據：LeBlanc 2018 (ISTAP Best Practice)；Van Tiggelen 2020 (Br J Dermatol, DOI:10.1111/bjd.18604)
3. 燒傷（淺層／部分層／全層）
深度臨床表現處置
淺層（一度）紅、痛、無水泡保濕、止痛
部分層（二度）水泡、滲液、劇痛非黏附覆蓋±抗菌敷料
全層（三度）蒼白/焦痂、無痛覺早期切痂＋植皮

急救：流動冷水冷卻約 20 分鐘（勿用冰）；依 ABA 準則評估燒傷中心轉診（面積、深度、部位、特殊族群）。

依據：ISBI 2016 (Burns, DOI:10.1016/j.burns.2016.05.013)；ISBI 2018 Part 2 (DOI:10.1016/j.burns.2018.09.012)；ABA referral criteria；WHO Burns
4. 開放性骨折（Gustilo–Anderson）
分級定義
Type I傷口 <1 cm，乾淨
Type II傷口 1–10 cm，中度軟組織損傷
Type IIIA廣泛軟組織損傷但骨膜覆蓋足夠
Type IIIB骨外露，需皮瓣重建
Type IIIC合併需修復之血管損傷
依據：Gustilo & Anderson 1976 (JBJS, DOI:10.2106/00004623-197658040-00004)；Gustilo 1984 (J Trauma, DOI:10.1097/00005373-198408000-00009)；AO Surgery Reference
5. 手術傷口（CDC 汙染分級——注意：這是汙染分級，不是深度分期）
級別定義
Clean無感染、未進入呼吸/消化/泌尿生殖道
Clean-contaminated控制下進入上述管腔，無明顯汙染
Contaminated開放新鮮外傷、術中明顯汙染、急性非化膿性發炎
Dirty / Infected舊外傷帶壞死組織、既存感染或臟器穿孔
依據：CDC NHSN Patient Safety Component Manual — SSI Event
6. 破傷風、咬傷與狂犬病暴露

破傷風：評估傷口型態（清潔/汙染）× 疫苗史 → 決定 Td/Tdap 追加與 TIG。
咬傷/狂犬病：立即肥皂水沖洗 15 分鐘 → 依動物種類與地區風險評估 PEP（疫苗±免疫球蛋白）。

依據：CDC tetanus wound management；CDC rabies PEP

二、慢性傷口（六大病因）

1. 糖尿病足潰瘍 DFU

核心評估：神經病變（單絲測驗）、血管（ABI/WIfI）、感染（IWGDF/IDSA 分級）、骨髓炎。

金律：減壓（offloading）是治療核心，不可被任何敷料取代。

分類：SINBAD（溝通與稽核）；感染用 IWGDF/IDSA；缺血肢體用 WIfI。

依據：IWGDF 2023（DOI:10.1002/dmrr.3648、3647）；IWGDF/IDSA 2023 (DOI:10.1093/cid/ciad527)；Lavery 2024 WHS (DOI:10.1111/wrr.13133)
2. 壓力性損傷 Pressure Injury

核心處置：減壓與翻身、支持面選擇、營養、水分管理；分期見 NPIAP 分期；敷料依分期與滲出（見 敷料中心）。

依據：EPUAP/NPIAP/PPPIA 2019；Gould 2024 WHS (DOI:10.1111/wrr.13130)
3. 動脈性潰瘍 Arterial Ulcer

特徵：遠端、邊界清楚、蒼白傷口床、疼痛；必做：客觀灌流評估；可行時先血行重建。

穩定乾性缺血壞死：保護保持乾燥，勿貿然清創；避免不當壓迫。
依據：Federman 2024 WHS (DOI:10.1111/wrr.13204)；Conte 2019 GVG (DOI:10.1016/j.jvs.2019.02.016)；Mills 2014 WIfI (DOI:10.1016/j.jvs.2013.08.003)
4. 靜脈性潰瘍 Venous Leg Ulcer

特徵：足踝上內側、滲液多、周邊鬱血性皮膚變化（CEAP C4–C6）。

壓力治療是核心——但治療前必先排除顯著動脈疾病（ABI）。
依據：Marston 2016 WHS (DOI:10.1111/wrr.12394)；Franks 2016 EWMA (DOI:10.12968/jowc.2016.25.sup6.s1)；Lurie 2020 CEAP (DOI:10.1016/j.jvsv.2019.12.075)
5. 混合型動靜脈潰瘍

同時具動靜脈成分；先評估動脈嚴重度，決定可否壓迫與壓迫強度；必要時先處理動脈問題。

依據：EWMA Lower Leg Ulcer 2023；WOCN LEAD 2024
6. 非典型傷口（PG、血管炎、鈣化防禦、惡性）

紅旗徵象：型態不典型、位置怪異、治療無反應、過度疼痛、邊緣異常增生 → 切片＋病因檢查。

壞疽性膿皮症（PG）活動期：避免積極清創（病理性惡化 pathergy）。
依據：Isoherranen 2019 EWMA (DOI:10.12968/jowc.2019.28.sup6.s1)；Maverakis 2020 (DOI:10.1038/s41572-020-0213-x)；Nigwekar 2018 NEJM (DOI:10.1056/NEJMra1505292)
7. 放射性傷口

急性放射性皮膚炎依 MASCC 2023／CTCAE v5.0 分級；慢性放射性潰瘍須排除復發惡性與骨壞死。

依據：Behroozian 2023 (Lancet Oncol, DOI:10.1016/S1470-2045(23)00067-0)；NCI CTCAE v5.0
8. 惡性／蕈狀傷口與緩和照護

目標轉為症狀控制與生活品質：滲液、異味、出血、疼痛、感染、周邊皮膚保護。

依據：EWMA Palliative Wound Care 2025；NCI PDQ Last Days of Life
